# varios — rama 17.0 (Odoo 17)

Módulos varios para **Odoo 17 Community**. Cada módulo es una carpeta en la raíz de la rama.
Los módulos para Odoo 19 están en la rama `19.0`.

| Módulo | Descripción |
|---|---|
| `kai_portal_set_password` | Contactos → Acción → "Establecer contraseña de portal": crea usuarios solo de portal y les fija la contraseña sin enviar correos; desactiva el correo de invitación del portal y los avisos de seguridad a usuarios de portal. Restringido al grupo "Puede establecer contraseña de portal". |
